# Adience Benchmark Dataset

## Описание

Датасет используется для задач распознавания пола и возраста по изображениям лиц. Он содержит фотографии пользователей, собранные из открытых источников, с аннотациями пола, возрастной группы и параметров положения лица.

В рамках проекта датасет применяется для задачи классификации пола человека по изображению лица.

## Характеристики

- **Тип данных:** изображения лиц  
- **Формат:** JPEG  
- **Разметка:** пол (f/m), возрастные группы, параметры положения лица  
- **Особенности:**  
  - наличие нескольких лиц на одном изображении  
  - разнообразие ракурсов, освещения и условий съёмки  
  - выровненные изображения лиц (aligned faces)  

## Структура аннотаций

Каждая запись содержит:

- `user_id` — идентификатор пользователя  
- `original_image` — имя исходного изображения  
- `face_id` — номер лица на изображении  
- `age` — возрастная группа  
- `gender` — пол (f — женский, m — мужской)  
- `x, y, dx, dy` — координаты bounding box  
- `tilt_ang` — угол наклона головы  
- `fiducial_yaw_angle` — угол поворота лица
