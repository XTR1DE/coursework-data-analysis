**# UTKFace Dataset**



**## Описание**

**Датасет содержит 23 705 изображений лиц с аннотациями возраста, пола и этнической принадлежности. Используется для задач распознавания возраста, пола и эмоций.**



**## Характеристики**

**- \*\*Количество изображений:\*\* 23 705**

**- \*\*Формат:\*\* JPEG**

**- \*\*Разметка:\*\* возраст, пол, этничность (в названии файла)**

**- \*\*Размер:\*\* \~700 МБ (архив)**
